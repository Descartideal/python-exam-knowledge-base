# OpenCV 形态学、轮廓与目标测量

关键词：erode dilate morphologyEx 开运算 闭运算 findContours contourArea boundingRect moments

## 从二值前景开始

形态学常作用于二值图。先把感兴趣的目标定义为非零前景，再选择结构元素。前景/背景反过来时，操作的直观效果也可能反过来。

| 操作 | 常见作用（白色为前景） |
|---|---|
| erode 腐蚀 | 缩小前景、去小突起 |
| dilate 膨胀 | 扩大前景、连接小间隙 |
| MORPH_OPEN 开运算 | 先腐蚀再膨胀，去小孤立前景 |
| MORPH_CLOSE 闭运算 | 先膨胀再腐蚀，填小孔/连小缝 |
| MORPH_GRADIENT | 膨胀与腐蚀的差，突出边界 |

```python
import numpy as np
import cv2
binary = np.zeros((120, 160), dtype=np.uint8)
binary[30:90, 40:110] = 255
binary[10, 10] = 255
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
print(np.count_nonzero(binary), np.count_nonzero(opened))
```

核形状和尺寸决定操作范围。大核会删掉小目标，不能把“噪声消失”当成唯一判断标准。

## 轮廓检测

```python
import numpy as np
import cv2
binary = np.zeros((120, 160), dtype=np.uint8)
cv2.rectangle(binary, (20, 20), (70, 90), 255, -1)
cv2.circle(binary, (115, 60), 20, 255, -1)
contours, hierarchy = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
print("外部轮廓数：", len(contours))
for contour in contours:
    area = cv2.contourArea(contour)
    perimeter = cv2.arcLength(contour, True)
    x, y, w, h = cv2.boundingRect(contour)
    print(area, perimeter, (x, y, w, h))
```

代码采用常见 OpenCV 4/5 的两个返回值接口；很老版本可能不同。RETR_EXTERNAL 只取外部轮廓，RETR_TREE 可保留嵌套层次。CHAIN_APPROX_SIMPLE 压缩部分冗余点。
轮廓面积是几何多边形面积，不一定与二值图非零像素数量完全相等。

## 面积筛选与标注

筛掉 contourArea 小于阈值的轮廓；使用 boundingRect 得到轴对齐框；用 rectangle 在彩色图上标注。不能把“每条轮廓”直接等同于“一个真实物体”，粘连、断裂、孔洞都会影响检测。

## 质心与形状

moments(contour) 返回矩字典；m00 非零时质心可由 m10/m00、m01/m00 得到。m00=0 时不能直接除。
approxPolyDP 按给定精度近似轮廓，minAreaRect 返回可旋转最小外接矩形；这些属于进一步拓展，先把二值、轮廓和面积基础掌握好。

## 流水线的验收

先看原图与阈值图；再看形态学是否误删有效目标；最后核对轮廓数、面积、框位置。每个中间结果都保存一张图，比只看最终“检测到 N 个”更容易排错。

练习：在合成图加入噪声点，比较开运算前后轮廓数；仅保留面积大于 100 的目标；画框并标面积。
