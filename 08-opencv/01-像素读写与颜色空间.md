# OpenCV 入门：图像数组、读写、像素和颜色

关键词：cv2 BGR RGB 灰度 shape uint8 imread imdecode 中文路径 像素 通道

## 图片就是数组

常见彩色图像为 (高,宽,3) 的 uint8 数组，灰度图为 (高,宽)。像素用 img[y,x] 访问，坐标标注用 (x,y)。这两个顺序不同，是常见错点。

```python
import numpy as np
import cv2
img = np.zeros((100, 160, 3), dtype=np.uint8)
img[:, :] = (0, 0, 255)  # BGR 的红色
print(img.shape, img.dtype)
print(img[20, 30])
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(gray.shape)
```

灰度不是随意取一个颜色通道，cvtColor 按转换规则组合通道。Matplotlib 显示彩色 OpenCV 图像前通常转 BGR→RGB。

## 最基本读写

imread 读取失败常返回 None，不一定抛文件异常；调用 shape/cvtColor 前检查。imwrite 返回成功布尔值，不能忽略失败。
路径含中文时，不同 OpenCV/系统构建可能表现不同。本库用 NumPy 读字节 + imdecode 解码以减少兼容问题：

```python
from pathlib import Path
import numpy as np
import cv2
ROOT = Path(__file__).resolve().parents[1]
p = ROOT / "10-测试数据" / "test.png"
if not p.is_file():
    raise FileNotFoundError(p)
img = cv2.imdecode(np.fromfile(str(p), dtype=np.uint8), cv2.IMREAD_COLOR)
if img is None:
    raise ValueError("无法解码图片")
ok, encoded = cv2.imencode(".png", img)
if not ok:
    raise ValueError("编码失败")
encoded.tofile("practice-copy.png")
```

IMREAD_COLOR 常返回三通道彩色图；IMREAD_GRAYSCALE 为灰度；IMREAD_UNCHANGED 可保留 alpha/原始位深等情况。后续算法必须检查实际通道数与 dtype。

## ROI 裁剪与副本

```python
import numpy as np
img = np.zeros((200, 300, 3), dtype=np.uint8)
crop = img[30:160, 40:220].copy()
print(crop.shape)  # (130,180,3)
```

切片终点不含；普通切片可能共享内存，修改 ROI 可能修改原图；需要独立图用 copy。坐标超边界的切片可能只是变小或变空，不一定主动报错，应检查 size。

## 通道与数值范围

cv2.split(img) 分离通道，cv2.merge([...]) 合并。uint8 的普通 NumPy 加法可能溢出回绕；cv2.add 对常见 uint8 图像采用饱和规则。例如 250+10，NumPy uint8 可能变 4，OpenCV 饱和到 255。
做归一化计算时先转换 float32，并明确是 0~1 还是 0~255，不随意混用。

## 绘图标注与窗口

rectangle、circle、line 的位置使用 (x,y)、颜色 BGR、thickness=-1 常表示填充。putText 默认字体主要适合基本拉丁字符，中文需额外方法。
imshow 显示后需要 waitKey 处理窗口事件，结束调用 destroyAllWindows。无 GUI 环境保存图片即可；本库批量例题不弹窗。
