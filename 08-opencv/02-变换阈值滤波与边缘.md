# OpenCV 变换、阈值、平滑与边缘

关键词：resize rotate warpAffine threshold Otsu adaptiveThreshold GaussianBlur medianBlur Canny

## 缩放与插值

```python
import numpy as np
import cv2
img = np.zeros((100, 200, 3), dtype=np.uint8)
small = cv2.resize(img, (100, 50), interpolation=cv2.INTER_AREA)
large = cv2.resize(img, None, fx=2, fy=2, interpolation=cv2.INTER_LINEAR)
print(small.shape, large.shape)
```

目标尺寸写 (宽,高)；INTER_AREA 常用于缩小，INTER_LINEAR 常用于普通放大，INTER_NEAREST 适合类别标签/离散掩膜，避免插值制造新类别值。
缩放会改变图像内容采样，reshape 不是真正缩放，不要拿 NumPy 变形代替 resize。

## 平移与旋转

```python
import numpy as np
import cv2
img = np.zeros((100, 160, 3), dtype=np.uint8)
cv2.rectangle(img, (40, 20), (100, 70), (0, 255, 0), -1)
h, w = img.shape[:2]
M = cv2.getRotationMatrix2D((w / 2, h / 2), 30, 1.0)
rotated = cv2.warpAffine(img, M, (w, h))
print(rotated.shape)
```

仿射矩阵为 2×3，warpAffine 输出尺寸仍写宽高。旋转后可能裁掉角部，若要完整保留需设计新画布。90° 旋转可使用 cv2.rotate。

## 固定阈值与 Otsu

```python
import numpy as np
import cv2
gray = np.tile(np.arange(256, dtype=np.uint8), (80, 1))
ret, binary = cv2.threshold(gray, 120, 255, cv2.THRESH_BINARY)
auto_ret, auto_binary = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(ret, auto_ret, np.unique(binary))
```

threshold 返回阈值和图，不是只返回图。THRESH_BINARY 的常见规则是大于阈值为最大值，否则为 0；INV 反转。Otsu 从分布估计阈值，适合某些双峰情形，不保证任何照片都完美。

## 自适应阈值

adaptiveThreshold 按局部邻域计算阈值，适合光照不均的某些文本图。常用 8 位单通道输入，blockSize 为大于 1 的奇数，C 为减去的常量。先确定目标前景/背景颜色，再决定是否用反转模式。

## 三种平滑方式

| 方法 | 意义 | 常见输入/参数 |
|---|---|---|
| blur | 均值平滑 | (3,3) 等核尺寸 |
| GaussianBlur | 高斯加权平滑 | (5,5)、sigmaX |
| medianBlur | 中值滤波 | ksize 为合适正奇数，常用于椒盐噪声 |

滤波降噪也会损失细节，核越大不一定越好。不同函数的 dtype 与核尺寸支持不同，遇到断言错误看具体参数。

## Canny 边缘流水线

```python
import numpy as np
import cv2
gray = np.zeros((100, 100), dtype=np.uint8)
gray[25:75, 25:75] = 255
blur = cv2.GaussianBlur(gray, (5, 5), 0)
edges = cv2.Canny(blur, 50, 150)
print(edges.shape, np.count_nonzero(edges))
```

常见顺序：读图→灰度→轻度平滑→Canny。低/高阈值与图像对比度相关，没有通用于所有图的参数。边缘图显示轮廓变化，不等同于完整物体分割。

练习：同图比较固定、Otsu、自适应阈值；逐渐增大高斯核，看细节变化；比较两个 Canny 阈值组合。
