# Python 离线知识库与本地 AI 助手

这是一个面向 **Python 初学者与课程备考** 的本地知识库。它把学习教程、API 速查、代码示例、练习答案和官方资料整理在同一个文件夹里，并提供可选的本地 AI 问答与 Python Agent，帮助你学习、检索资料、分析数据和生成图表。

它的主要用途是：**平时系统学习，考前独立练习，在允许使用本地资料的考试中断网检索函数和代码模板。** 是否允许带资料、安装软件或使用示例，以课程要求为准。

## 可以用它做什么

- 从零学习 Python、终端、pip、虚拟环境、文件路径与常见报错。
- 学习 turtle、NumPy、Pandas、Matplotlib、jieba、WordCloud 和 OpenCV 七个库。
- 用中文用途或英文函数名搜索知识点，例如“班级平均分”“广播”“灰度化”“reshape”。
- 查阅包含参数、返回值、示例和常见错误的 API 卡片。
- 运行成绩分析、中文词频词云、图像处理等例题，修改输入再核对结果。
- 完成分级练习，用参考答案、覆盖清单和错题模板检查掌握程度。
- 离线阅读 42 份官方文档正文与许可资料，而不必访问官网。
- 用本地 Qwen3.6-35B-A3B 模型结合资料回答问题，查看回答来源。
- 让 Agent 生成并实际运行 Python，处理 CSV、Excel、文本和图片，保存结果。

## 最快开始：只阅读资料

1. 下载整个仓库并解压，或者使用 Git 克隆。
2. 在 Windows 上双击 **打开知识库.cmd**；其他系统可以直接用浏览器打开 **知识库.html**。
3. 先看“00-环境与入门”，再按“完整学习目录”学习；需要速查时使用顶部搜索框。
4. 官方文档正文也可以从侧栏“14-官方正文”中搜索和阅读。

**阅读和搜索不需要联网，也不需要安装 Python。** 入口自带资料与检索脚本，不使用 CDN、在线字体或远程图片。请下载整个仓库，保留目录结构；只保存首页文件不包含所有可下载源码、安装包和测试数据。

## 本地 AI 问答与 Python Agent

此入口适用于 Windows x64，需要先安装 Python 3.12、创建学习环境，并单独安装 Ollama（安装来源： https://ollama.com/download/windows ）。无需云端 API 密钥；仓库不包含大模型权重或 Ollama 安装器。

1. 双击 **安装学习环境.cmd**，再运行 **检查环境.cmd**。
2. 安装并启动 Ollama，确保 `ollama` 命令可用。
3. 双击 **启动AI助手.cmd**，浏览器打开 http://127.0.0.1:8765。
4. 首次启动会自动以 **16 线程、64MiB 分片** 下载 Qwen3.6-35B-A3B **Q4_K_M**（约 **22.29GB**），支持断点续传，并校验完整文件的 SHA-256 后导入 Ollama。
5. 模型准备完成后选择“知识库问答”或“Agent 操作”；准备期间可先使用“仅检索资料”。

已验证配置为 **48GB 内存、RTX 5070 Laptop 8GB 显存**，采用内存与显卡混合推理，配置为模型原生 **262,144 tokens（256K）上下文**。该配置已在本机成功加载；长文本越多，首轮处理时间越长，低内存电脑可在 `tools/local_assistant/settings.py` 调低 `CONTEXT_LENGTH`。下载和导入期间需预留足够磁盘空间，模型默认保存在用户目录的 `.ollama/models`。

检索使用中文全文检索与可选 BGE-M3 语义检索。如果本机默认 Ollama 服务已有 `bge-m3`，助手会在后台建立语义索引；新电脑可自行运行 `ollama pull bge-m3` 准备该模型。未安装时仍可使用全文检索。初次模型下载需要网络，准备完成后问答和数据处理可离线运行。

可以这样提问：

- “解释 NumPy 广播，结合本地例题说明。”
- “分析 10-测试数据里的学生成绩，生成各班均分 CSV 和柱状图，并实际运行验证。”
- “清洗我上传的 CSV，按类别统计总金额，再保存结果。”

“添加数据”支持最多 8MB 的 CSV、Excel、文本、JSON 和图片，保存在 `10-测试数据/AI上传`。每项任务的代码、表格和图表保存在 `13-运行结果/AI助手/任务编号`，页面提供下载及预览。

默认每次写文件和执行 Python 都需在页面确认；可选择“本次会话自动执行”，刷新后恢复关闭。单次 Python 运行最多 60 秒，每个任务最多 10 轮模型操作。运行器检查普通 Python 的文件写入、网络和子进程操作，但**不是操作系统沙箱**，执行代码仍使用当前账号权限。运行前可展开执行记录检查代码。

新回复和 Agent 执行记录会保持当前阅读位置；点击 **查看最新 ↓** 才跳到最新内容。双击 **停止AI助手.cmd** 可停止网页服务及部署工作；关闭浏览器不会停止后台下载。

左栏可搜索、切换历史对话，新建对话保留已有内容。对话、资料来源、执行记录和结果链接保存在本地数据库，刷新或重启后可继续提问。顶部显示上下文已用 tokens、百分比及输入/生成用量；生成过程中标明估算，完成后使用 Ollama 实际计数。只在接近上限时压缩旧内容，为回复预留 8192 tokens。

详细操作、模型校验值、端口和故障处理见 [AI助手使用说明](AI助手使用说明.md)。

## 运行 Python 例题

电脑需已有 Python。自带离线库安装包适用于 **Windows x64（Intel/AMD）与 Python 3.12**。

1. 双击 **安装学习环境.cmd**，创建本项目的 `.venv`，只从本地 wheel 安装库和依赖。
2. 双击 **检查环境.cmd**，查看解释器和库是否可用。
3. 双击 **运行例题.cmd**，按菜单数字选择例题。
4. 在 **13-运行结果** 查看输出的 CSV、JSON、PNG 等文件。

也可以在仓库根目录的 PowerShell 中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\15-离线安装包\wheels -r .\15-离线安装包\requirements-离线.txt
.\.venv\Scripts\python.exe .\09-综合例题\学生成绩分析.py
```

`--no-index` 禁止联系在线包索引。安装包与版本清单都在本地，安装失败不会自动联网补包。

本仓库**不包含 Python 安装器**。其他 Python 版本、Windows ARM 或 macOS/Linux 需要考前准备兼容环境；资料阅读仍可离线进行。turtle 窗口需要 Tk，中文绘图与词云需要本机中文字体。已安装环境可以在考前配置 `KB_FONT` 指定字体路径。

## 推荐学习方法

按“环境 → Python 基础 → 数组/表格 → 绘图 → 文本/词云 → 图像 → 综合练习”学习。
先读分步教程，再运行小例子并修改参数，最后独立做题、核对答案。API 速查用于查忘记的调用方式，不能代替理解数据类型、形状和业务规则。

学习重点与练习是备考建议，不是老师确认的全部命题范围。官方正文是选定页面的本地文字备份，不是整个官网镜像；没有同步官网全部图片和互动模块。

## 更新自己的笔记

在对应章节新增或修改 UTF-8 的 `.md`、`.txt` 或 `.py` 文件，双击 **更新检索.cmd**，然后刷新知识库网页。更新索引不联网；不要直接修改生成的知识库.html。

AI 助手使用独立索引，新增笔记后在助手页面点击 **更新知识库索引**；语义索引在后台更新。

`.venv`、Python 缓存、编辑器配置、`.local-assistant` 中的对话与日志、上传数据及 Agent 输出不进入 Git。静态知识库打包也会排除 `AI上传` 目录，避免把上传文本嵌入首页。模型默认在仓库外，不随项目上传。换电脑后重新创建环境和准备模型，保留本地 wheel；不应依赖复制虚拟环境来迁移。
