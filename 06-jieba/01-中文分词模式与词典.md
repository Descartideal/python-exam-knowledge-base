# jieba 入门：中文分词模式与自定义词典

关键词：分词 精确模式 全模式 搜索模式 cut lcut posseg HMM add_word userdict

## 为什么需要分词

英文词通常由空格分隔，中文“我学习数据分析”没有天然空格。分词工具尝试将连续文字拆成有意义的词。它依赖词典和模型，并不保证每一句都只有唯一正确拆法。
先安装 jieba，然后在 Python 使用 import jieba；安装命令见环境入门章节。

## 三种模式

```python
import jieba
text = "我在北京大学学习数据分析"
print(jieba.lcut(text))
print(jieba.lcut(text, cut_all=True))
print(list(jieba.cut_for_search(text)))
```

| 模式 | 目的 | 适合词频统计吗 |
|---|---|---|
| 精确模式 | 尽量将句子划分成一组词 | 通常适合 |
| 全模式 | 列出可匹配的更多词 | 可能重叠，不宜当作普通出现次数 |
| 搜索模式 | 在精确结果基础上拆出部分短词 | 适合检索，不宜直接当原文词频 |

cut 返回生成器，lcut 返回列表。需要多次使用分词结果时先转列表；生成器被遍历后一般不会自动从头再来。

## 未登录词与 HMM

HMM 参数控制对未登录词的识别策略。`jieba.lcut(text,HMM=False)` 可用于比较关闭该机制后的分词。不要把 HMM 变化理解为“总有一个固定正确答案”；检查你的词语定义和任务。

## 自定义词

```python
import jieba
jieba.add_word("Python知识库", freq=10000)
print(jieba.lcut("我正在建立Python知识库"))
jieba.del_word("Python知识库")
```

add_word 在当前进程调整词典，del_word 删除词典条目，suggest_freq 可帮助调整某些组合拆分；效果还可能受 HMM 影响，调整后用样例验证。

## 用户词典文件

一行一般写“词语 可选词频 可选词性”，保存为 UTF-8：

```text
数据分析 100 n
系统设计 100 n
中文分词 100 n
```

```python
from pathlib import Path
import jieba
ROOT = Path(__file__).resolve().parents[1]
jieba.load_userdict(str(ROOT / "10-测试数据" / "userdict.txt"))
print(jieba.lcut("课程包括数据分析和系统设计"))
```

本知识库样例提供用户词典来稳定几个课程术语。不同词典和版本分词结果可能变化，不能仅靠和某张截图完全一致判断程序对错。

## 词性标注

```python
import jieba.posseg as pseg
for word, flag in pseg.cut("学习Python可以帮助数据分析"):
    print(word, flag)
```

词性标签可帮助筛选名词/动词，但也是模型判断，不是严格语法证明。考试题指定按名词提取时再用词性，不要擅自过滤掉所有其他词。
