# 文本清洗、词频统计与关键词提取

关键词：Counter 停用词 标点 top10 TF-IDF TextRank extract_tags textrank 词频

## 明确要统计的对象

字符频次不是词频；搜索模式生成的短词频次不等于原文中独立词语出现次数；关键词的权重也不是出现次数。
一个稳妥流程：读取文本 → 确认编码 → 精确分词 → 标准化 → 过滤 → Counter 计数 → 排序 → 保存。

```python
from collections import Counter
import jieba
text = "Python帮助学习。学习Python也需要实践！"
stop = {"也", "需要"}
tokens = jieba.lcut(text)
words = []
for token in tokens:
    word = token.strip()
    if not word or word in stop:
        continue
    if not any(ch.isalnum() for ch in word):
        continue
    words.append(word)
freq = Counter(words)
print(words)
print(freq.most_common(10))
```

isalnum 对部分中文、字母和数字也为真，这里用于排除纯标点，不是在严格限制“只保留汉字”。数字是否保留、英文是否统一小写、单字是否保留，应按题目规定。

## 停用词文件

```python
from pathlib import Path
ROOT = Path(__file__).resolve().parents[1]
stop = {line.strip() for line in (ROOT / "10-测试数据" / "stopwords.txt").read_text(encoding="utf-8").splitlines() if line.strip()}
print(stop)
```

没有适合所有题目的停用词表。本库使用小型演示表，不自动下载来源不明的大词表。过滤 len(word)>1 会丢掉“水”“书”等有意义单字，使用前先判断任务。

## 稳定排序

Counter.most_common 按次数降序；同频词的顺序与首次遇到顺序有关。需要明确“同频按字典序”时：

```python
from collections import Counter
freq = Counter({"B": 2, "A": 2, "C": 1})
print(sorted(freq.items(), key=lambda p: (-p[1], p[0])))
```

## TF-IDF 关键词

```python
import jieba.analyse
text = "数据分析课程关注数据清洗与Python编程，学生通过编程完成数据分析实践。"
tags = jieba.analyse.extract_tags(text, topK=5, withWeight=True)
print(tags)
```

TF-IDF 将当前文本词频与逆文档频率结合；默认使用工具自带的 IDF 资料，不是每次都从你的单篇文章重新训练整个语料库。withWeight=False 返回词列表，True 返回词与权重。
可用 allowPOS 限定词性，set_stop_words 设置关键词工具使用的停用词；这与自己 Counter 前的停用词过滤是不同步骤。

## TextRank 关键词

```python
import jieba.analyse
text = "数据分析与图像处理是实践课程，学生学习数据分析方法并通过编程完成图像处理任务。"
print(jieba.analyse.textrank(text, topK=5, withWeight=True))
```

TextRank 基于词语在文本中的关联，短文本可能不足以构建有效结果。两种算法结果不同不意味着必有一个程序错误；题目指定方法就使用指定方法。

## 给词云准备数据

词云需要 {词:正权重}。想准确呈现原文词频时用 Counter；想呈现关键词权重时用 extract_tags 的结果转字典，并注明其含义。生成前检查非空、权重有效。

练习：统计前 10 个词；给同频词固定次序；比较词频前五与 TF-IDF 前五；解释差别而不是强行让它们一致。
