# WordCloud 入门与中文词云完整流程

关键词：中文词云 字体 分词 空格 generate generate_from_frequencies to_file

## 词云不是分词工具

WordCloud 将词和权重排布成图片，通常不负责高质量中文分词。中文词云需要先用 jieba 切词，再选择使用分词文本或词频字典。
流程：TXT → 分词 → 过滤 → Counter → WordCloud → PNG。

## 两种生成入口

- generate(text)：将文本交给 WordCloud 内部的文本处理；中文通常先将词用空格连接。
- generate_from_frequencies(freq)：直接使用词与权重映射，适合精确控制停用词、计数与关键词权重。

本课程的词频题优先第二种，避免内部组合词等规则改变你已经统计好的次数。

## 可以独立运行的中文示例

```python
from pathlib import Path
from collections import Counter
import jieba
from wordcloud import WordCloud

text = "学习Python，学习数据分析，实践编程。"
words = [w for w in jieba.lcut(text) if any(c.isalnum() for c in w)]
freq = Counter(words)
font = Path("C:/Windows/Fonts/msyh.ttc")
if not font.exists():
    raise FileNotFoundError("请改为可用中文字体")
if not freq:
    raise ValueError("没有有效词语")
wc = WordCloud(font_path=str(font), width=900, height=500,
               background_color="white", max_words=100,
               random_state=42, collocations=False)
wc.generate_from_frequencies(freq)
wc.to_file("practice-chinese-cloud.png")
```

to_file 返回自身对象，不是输出文件名；width/height 指画布尺寸，结果排布可受 scale、mask 等参数影响。

## 中文字体怎么找

Windows 常见候选：微软雅黑 msyh.ttc、黑体 simhei.ttf、宋体 simsun.ttc。实际存在情况取决于系统。检查 C:/Windows/Fonts，也可以使用自己已有且许可适合的中文字体。
仅设置 UTF-8 不能修复字体方框，编码与字体是不同环节。不要下载字体后只传字体名字，font_path 通常需要实际文件路径。
可运行例题会自动找常见字体；也可在 PowerShell 设置 `$env:KB_FONT = '你的字体完整路径'` 后运行。

## 显示词云

```python
from wordcloud import WordCloud
import matplotlib.pyplot as plt
wc = WordCloud(width=600, height=300, background_color="white").generate("python python data analysis")
fig, ax = plt.subplots()
ax.imshow(wc, interpolation="bilinear")
ax.axis("off")
fig.savefig("practice-cloud-display.png", dpi=150, bbox_inches="tight")
plt.close(fig)
```

直接 to_file 导出词云画布；用 Matplotlib 保存可能额外受画布尺寸、留白、dpi 影响。如果题目要求精确像素尺寸，用 to_file 并检查实际图片尺寸。

## 验收词云而不只看好不好看

词频正确、词语完整、停用词已过滤、汉字能显示、输出尺寸正确、图片确实保存。词面积受排布和缩放策略影响，不应从图片大小精确反推词频。

练习：同一份词频换背景和色图；固定种子比较两次输出；把词频换成关键词权重并说明含义。
