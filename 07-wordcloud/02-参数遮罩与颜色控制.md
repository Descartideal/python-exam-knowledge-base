# WordCloud 参数、遮罩与颜色控制

关键词：mask 白色区域 colormap recolor ImageColorGenerator scale relative_scaling 停用词

## 常见参数分组

| 类别 | 参数 | 作用 |
|---|---|---|
| 尺寸 | width、height、scale | 布局尺寸与输出缩放 |
| 字体 | font_path、min_font_size、max_font_size、font_step | 字体文件与大小限制 |
| 词语 | max_words、stopwords、collocations | 最大词数与文本处理 |
| 布局 | mask、prefer_horizontal、margin、random_state | 可绘区域、方向、间距与随机性 |
| 颜色 | background_color、colormap、color_func、mode | 背景、词色与颜色模式 |
| 权重 | relative_scaling、normalize_plurals | 频率缩放与部分文本规则 |

不要把所有参数都随便加上：先生成基本词云，再针对题目控制一个变量。部分参数只影响 generate 的内部文本处理，对已给定的词频映射不再重新过滤。

## 遮罩的关键规则

mask 是 NumPy 数组；通常白色值 255 表示不允许绘制的区域，其他值表示可绘制。mask 给定后布局尺寸由遮罩决定，而不是简单沿用 width/height。

```python
import numpy as np
from wordcloud import WordCloud
y, x = np.ogrid[:300, :300]
inside = (x - 150) ** 2 + (y - 150) ** 2 <= 130 ** 2
mask = np.where(inside, 0, 255).astype(np.uint8)
wc = WordCloud(mask=mask, background_color="white", max_words=30,
               random_state=42, colormap="viridis", contour_width=1)
wc.generate_from_frequencies({"Python": 8, "data": 5, "study": 3, "plot": 2})
wc.to_file("practice-circle-cloud.png")
```

圆内部为 0，外部为 255。反过来会把词画到圆外。真实图片遮罩先检查尺寸、背景颜色和数组通道，不要仅凭扩展名认为可直接使用。

## 颜色方案

colormap 用 Matplotlib 色图名称；color_func 可以自定义每个词的颜色；recolor 在现有排布上重新着色，而不必重新排布。
ImageColorGenerator 可按参考图片生成词色，参考图片尺寸应与布局相适配。题目只要求白底中文词云时，没有必要引入复杂颜色图片。

## 透明背景

需要透明时使用 mode="RGBA"、background_color=None，并保存 PNG。默认 RGB 图片不保存 alpha；JPEG 也不支持常规透明背景。

## 词频、字体与可绘区域共同影响排布

词太多、字体下限太大、遮罩有效面积太小，可能无法放下想要的词。max_words 是上限，不保证全部显示。空词频与全部无效权重先在生成前检查。
从 frequencies 生成时需要自己处理停用词，不能以为构造 WordCloud(stopwords=...) 会再次过滤整个频率字典。

练习：生成圆形遮罩；试验同一 mask 与不同 max_words；导出透明 PNG；检查 alpha 通道是否存在。
