# Pandas 筛选、缺失值、分组与时间

关键词：loc iloc 多条件 链式赋值 to_numeric dropna fillna groupby agg transform datetime

## loc 和 iloc 分别回答什么问题

```python
import pandas as pd
df = pd.DataFrame({"姓名": ["A", "B", "C"], "成绩": [55, 80, 90]}, index=[10, 20, 30])
print(df.loc[10:20, ["姓名", "成绩"]])  # 标签切片含终点
print(df.iloc[0:2, 0:2])             # 位置切片不含终点
print(df.loc[df["成绩"] >= 60, "姓名"])
```

DataFrame 的 `df[0:2]` 等快捷写法在不同情境容易混淆，入门时显式使用 loc/iloc。索引排序与重复标签会影响标签切片的行为。

## 多条件与赋值

```python
import pandas as pd
df = pd.DataFrame({"成绩": [55, 80, 90], "班级": ["A", "A", "B"]})
mask = (df["成绩"] >= 60) & (df["班级"] == "A")
print(df.loc[mask])
df.loc[df["成绩"] < 60, "状态"] = "需补考"
print(df)
```

条件每部分加括号，使用 &/|/~。更新原表用单次 loc；不要写 df[mask]["成绩"]=...。Pandas 新旧版本的复制机制不同，使用清晰的选择与赋值方式可减少歧义。

## 清洗的顺序

1. 检查列名与单位；去不必要空白。
2. 转换数据类型，不能转换的值明确标为缺失或报错。
3. 规定缺失值和非法值怎么处理。
4. 按业务主键检查重复，不随意删掉合法记录。
5. 统计并记录排除多少行。

```python
import pandas as pd
df = pd.DataFrame({"成绩": ["88", "缺考", "101", None]})
df["成绩"] = pd.to_numeric(df["成绩"], errors="coerce")
valid = df.dropna(subset=["成绩"])
valid = valid.loc[valid["成绩"].between(0, 100)].copy()
print(valid)
```

dropna 删除缺失，fillna 填补；ffill 用前一个有效值，bfill 用后一个。学生分数不能因为技术方便就用前一个学生的分数填补。`isna` 识别缺失，不能用 `== np.nan`。

## 分组与聚合

```python
import pandas as pd
df = pd.DataFrame({"班级": ["A", "A", "B"], "成绩": [60., 90., 80.]})
summary = df.groupby("班级").agg(
    平均分=("成绩", "mean"),
    最高分=("成绩", "max"),
    有效人数=("成绩", "count"),
)
print(summary.sort_values("平均分", ascending=False))
df["班内均分"] = df.groupby("班级")["成绩"].transform("mean")
print(df)
```

agg 合并为每组一个结果；transform 返回与原数据对应长度的结果，适合给每个学生标注班均分。count 不数缺失值，size 数行数。分组键缺失默认可能被排除，题目需要保留时了解 dropna=False。

## 日期与字符串列

```python
import pandas as pd
df = pd.DataFrame({"日期": ["2026-10-01", "无效"], "姓名": [" A ", "B"]})
df["日期"] = pd.to_datetime(df["日期"], errors="coerce")
df["姓名"] = df["姓名"].str.strip()
print(df["日期"].dt.month)
print(df["姓名"].str.contains("A", na=False))
```

.str 提供整列文本操作，.dt 提供日期属性。无法解析的日期在 errors="coerce" 下变成 NaT；需要明确日期格式/时区时显式指定，不依赖猜测。

### 混合日期格式

同列同时出现 `YYYY/MM/DD` 与 `YYYY-MM-DD` 时，`errors="coerce"` 只决定解析失败如何处理，不会自动启用逐条混合格式推断。格式确定且一致时优先给出 `format`；确需混合解析时使用 `format="mixed"`：

```python
dates = pd.Series(["2025/03/04", "2025-07-09", "无效", None])
parsed = pd.to_datetime(dates, format="mixed", errors="coerce")
result = parsed.dt.strftime("%Y-%m-%d").fillna("INVALID")
assert result.tolist() == ["2025-03-04", "2025-07-09", "INVALID", "INVALID"]
```

类似 `01/02/2025` 的日期有日/月歧义，要先确定约定，必要时指定 `dayfirst`；不要把解析成功等同于日期含义已经确认。参数依据：[pandas.to_datetime 官方说明](https://pandas.pydata.org/docs/reference/api/pandas.to_datetime.html)。本例在项目 pandas 3.0.3 中核对通过。
