# Pandas 合并、拼接、透视与综合处理

关键词：merge concat join pivot pivot_table melt 去重 对齐 apply map

## concat 与 merge 的区别

concat 将同类表沿行/列拼接；merge 按匹配键连接不同信息。将两个班学生放一起用 concat，将学生姓名表与成绩表按学号关联用 merge。

```python
import pandas as pd
a = pd.DataFrame({"id": [1, 2], "score": [80, 90]})
b = pd.DataFrame({"id": [3], "score": [70]})
print(pd.concat([a, b], ignore_index=True))
names = pd.DataFrame({"id": [1, 2, 4], "name": ["A", "B", "D"]})
print(a.merge(names, on="id", how="left", validate="one_to_one"))
```

concat 默认按列名/索引对齐，缺失位置补缺失值；ignore_index 重新编号。merge 的 inner 保留交集、left 保留左表键、outer 保留并集。
键重复会产生多对多配对，可能让行数变大。用 validate 声明一对一/多对一等要求；用 indicator=True 检查匹配来源。

## 去重必须选对键

drop_duplicates() 按整行去重；subset=["学号"] 按学号；keep="last" 保留最后一条。一个学生考了多次时，学号不是足够的唯一键；可能需要学号+考试日期。

## 标签对齐

```python
import pandas as pd
a = pd.Series([10, 20], index=["A", "B"])
b = pd.Series([1, 2], index=["B", "C"])
print(a + b)  # 按标签，不是按位置
print(a.add(b, fill_value=0))
```

Pandas 运算会按标签对齐；想按位置计算时需要确认顺序再转数组，不能因为长度相同就认为两个对象一一对应。

## 透视表

```python
import pandas as pd
df = pd.DataFrame({"班级": ["A", "A", "B", "B"], "科目": ["语文", "数学", "语文", "数学"], "成绩": [80, 90, 70, 85]})
wide = df.pivot(index="班级", columns="科目", values="成绩")
print(wide)
print(df.pivot_table(index="班级", columns="科目", values="成绩", aggfunc="mean"))
print(wide.reset_index().melt(id_vars="班级", var_name="科目", value_name="成绩"))
```

pivot 不做聚合，行列键组合重复时会报错；pivot_table 可以按 aggfunc 聚合重复项；melt 把宽表转成长表。题目指定“按班级、科目平均分”时，groupby 或 pivot_table 都能表达，但输出形状不同。

## map、apply 与向量化

```python
import pandas as pd
df = pd.DataFrame({"成绩": [55, 80, 90]})
df["及格"] = df["成绩"] >= 60
df["等级"] = df["及格"].map({True: "通过", False: "未通过"})
print(df)
```

简单整列运算优先向量化，映射优先 map；apply 可用于自定义函数，但不要把所有清洗都写成逐行 apply。学习时首先明确函数输入是一个数、一列还是一行。

## 一个可靠的成绩流程

读 CSV → 检查需要的列 → 转数值 → 区分缺考与非法值 → 记录排除行数 → 筛选/分组 → 明确排序 → 保存 CSV/图 → 重新读取核对。
输出文件名和规则作为参数更易复用。清洗后的表用 copy 明确独立数据，保留原表方便审计。

练习：用学号关联班级；故意加入重复键检查 validate；把多科成绩长表变成班级×科目的均分表；再恢复成长表。
