# Pandas 入门：列、索引、类型与读写

关键词：Series DataFrame index columns dtype CSV Excel read_csv head info describe

## 一张表的三部分

DataFrame 可看作带标签的二维表：行索引 index、列名 columns、各列数据。Series 是带索引的一列数据。行索引不一定是 0、1、2，也不一定是学生姓名。

```python
import pandas as pd
df = pd.DataFrame({"姓名": ["小王", "小李"], "成绩": [88, 55]})
print(df.shape, df.columns.tolist(), df.index.tolist())
print(type(df["成绩"]))     # Series
print(type(df[["成绩"]]))   # DataFrame
print(df.dtypes)
```

单方括号选列名通常得 Series，列名列表通常保留二维表；该差异会影响后续代码。

## 读取文件后先看结构

```python
from pathlib import Path
import pandas as pd
ROOT = Path(__file__).resolve().parents[1]
df = pd.read_csv(ROOT / "10-测试数据" / "scores.csv", encoding="utf-8")
print(df.head())
df.info()
print(df.describe(include="all"))
print(df.columns.tolist())
```

不要读完立刻对全表 mean：文件含中文“缺考”，成绩列可能不是数值类型。info 会打印类型与非缺失数，返回 None；describe 的内容随列类型变化。

## read_csv 常用参数

| 参数 | 用途 | 典型情况 |
|---|---|---|
| encoding | 文本编码 | utf-8、utf-8-sig、gb18030 |
| sep | 分隔符 | 逗号、制表符 |
| header | 哪行是表头 | 无表头时 header=None |
| names | 自己提供列名 | 无表头数据 |
| usecols | 只读部分列 | 大表只要班级、成绩 |
| dtype | 指定列类型 | 学号读取为字符串，保留前导零 |
| na_values | 额外缺失标记 | 缺考、-- |
| index_col | 指定索引列 | 已保存行索引的文件 |
| parse_dates | 尝试解析日期列 | 时间序列 |

学号 001 若被当成数字会丢前导零；用 dtype={"学号":str} 明确。字段实际为“缺考”时可用 na_values=["缺考"] 或后续 to_numeric。

## Excel 与输出

```python
import pandas as pd
df = pd.DataFrame({"姓名": ["小王"], "成绩": [88]})
df.to_csv("practice-scores.csv", index=False, encoding="utf-8-sig")
df.to_excel("practice-scores.xlsx", index=False)
print(pd.read_excel("practice-scores.xlsx", sheet_name=0))
```

.xlsx 处理通常需要 openpyxl，已在 requirements 中。CSV 不是 Excel 工作簿：不能通过改扩展名把 CSV 真正变成 .xlsx。to_csv 默认包含行索引；一般业务表用 index=False。

## 列名与索引整理

```python
import pandas as pd
df = pd.DataFrame({" name ": ["A", "B"], "score": [80, 90]})
df.columns = df.columns.str.strip()
df = df.rename(columns={"name": "姓名", "score": "成绩"})
print(df.set_index("姓名"))
print(df.set_index("姓名").reset_index())
```

set_index 默认返回新表；reset_index 默认把原索引变成普通列，drop=True 可丢弃原索引。标签可能重复，不能未经检查就当作唯一主键。

练习：读取成绩 CSV，检查真实列名与类型；只导出姓名、成绩两列；重新读取并确认没有多出 Unnamed:0。
