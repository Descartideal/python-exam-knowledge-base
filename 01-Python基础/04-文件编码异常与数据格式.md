# 文件路径、编码、CSV、JSON 与异常

关键词：文件读写 Path csv json with UTF-8 BOM 编码 try except

## 路径先分清基准

`Path("data.txt")` 相对当前工作目录，不一定相对 .py 文件。位于章节目录的例题可以这样定位知识库：

```python
from pathlib import Path
ROOT = Path(__file__).resolve().parents[1]
p = ROOT / "10-测试数据" / "article.txt"
print(p.exists(), p.resolve())
text = p.read_text(encoding="utf-8")
print(text[:30])
```

__file__ 在普通脚本中有值，交互窗口或某些 notebook 中可能没有；这些场景直接指定 ROOT 路径。parents[1] 适用于本知识库的“根目录/章节/脚本.py”结构，不是任何深度通用。

## 文本与二进制

文本用 r/w/a 和 encoding，二进制用 rb/wb，得到 bytes。图片不是普通文本，不能用 read_text 读取。
with 会在代码块结束时关闭文件；写入 w 会覆盖原有内容，a 会在末尾追加。读文件不会自动创建不存在的目录。

```python
from pathlib import Path
p = Path("practice-output.txt")
with p.open("w", encoding="utf-8") as f:
    f.write("第一行\n第二行\n")
with p.open("r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip("\n"))
```

## 中文与 UTF-8 BOM

同样的文字可能用不同编码保存。编码不匹配可导致 UnicodeDecodeError 或乱码。本库文本默认 UTF-8；某些 Windows/Excel 导出 CSV 带 BOM，读取可用 utf-8-sig。某些旧中文文件可能为 GB18030，需要确认来源后再指定。
`errors="ignore"` 可能悄悄丢字符，不应作为默认清洗办法。

## 标准库读 CSV

```python
from io import StringIO
import csv
source = StringIO('name,score\n"A, B",80\nC,90\n')
for row in csv.DictReader(source):
    print(row["name"], int(row["score"]))
```

CSV 引号内可以有逗号，不能可靠地用普通 split(",") 代替 csv。实际文件用 `open(..., newline="", encoding=...)`；DictReader 按列名生成字典。

## JSON 保存结构化数据

```python
import json
from pathlib import Path
data = {"班级": "7班", "成绩": [80, 90]}
text = json.dumps(data, ensure_ascii=False, indent=2)
Path("practice-data.json").write_text(text, encoding="utf-8")
restored = json.loads(text)
print(restored["成绩"])
```

dumps/loads 面向字符串，dump/load 面向文件对象。NumPy 数组需先 tolist，NumPy 数值常需转 Python int/float；DataFrame 使用其导出接口。

## 异常处理的层次

```python
try:
    value = int("缺考")
except ValueError as exc:
    print("该成绩不是整数：", exc)
else:
    print("转换成功", value)
finally:
    print("无论成功失败都会执行")
```

先确定异常究竟应修复、跳过还是向上报告。不要裸 except 后继续假装成功。raise 可主动报告不合法输入；计算阶段通常检查空数据、缺失列、尺寸和类型。
