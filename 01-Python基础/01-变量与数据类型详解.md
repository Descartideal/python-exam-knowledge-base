# 变量、数字、字符串与容器

关键词：变量 类型 int float str bool None list tuple dict set 可变对象

## 变量是名称与对象的绑定

`score = 80` 把名称 score 绑定到整数对象。`=` 赋值，`==` 比较。变量可以重新绑定，不等于对象本身都能原地改变。

```python
score = 80
print(type(score))
score = "80"
print(type(score))
print(int(score) + 5)
```

输入函数 input 返回字符串；做数值运算前转换类型。`int("3.5")` 会失败，`float("3.5")` 才能得到小数。`int(3.9)` 向零截断，并不是四舍五入。

## 数字与比较

```python
print(7 / 2)    # 3.5 真除法
print(7 // 2)   # 3 整除
print(7 % 2)    # 1 余数
print(2 ** 3)   # 8 幂
print(60 <= 80 <= 100)
print(abs(-5), round(3.14159, 2))
```

浮点数可能有精度误差，不要一律用 == 判断运算结果相等。数学数值接近时用 math.isclose；数组用 np.isclose/np.allclose。round 在边界上的行为也受到浮点表示和舍入规则影响。

## 字符串、索引与切片

```python
s = "Python学习"
print(s[0], s[-1])
print(s[0:6], s[::2], s[::-1])
print("  a,b,c  ".strip().split(","))
print("-".join(["a", "b", "c"]))
print(f"分数：{88.456:.2f}")
```

索引从 0 开始，负数从末尾计数；切片 `[start:stop:step]` 不含 stop。字符串不可原地改某个字符，需要产生新字符串。`len` 返回字符数，不是 UTF-8 字节数。

## 容器怎么选

| 类型 | 特点 | 常用操作 | 场景 |
|---|---|---|---|
| list | 有顺序、可修改、可重复 | append、extend、pop、切片 | 多个成绩 |
| tuple | 有顺序、结构不可修改 | 索引、解包 | 坐标、shape |
| dict | 键→值，保留插入顺序 | get、items、update | 学生→成绩 |
| set | 元素唯一，无索引顺序 | add、交并差 | 去重、成员检测 |

```python
scores = [60, 80]
scores.append(100)
scores.extend([75, 90])
last = scores.pop()
person = {"name": "小王", "score": 80}
print(person.get("class", "未知"))
for key, value in person.items():
    print(key, value)
print({1, 2} | {2, 3})
print({1, 2} & {2, 3})
x, y = (10, 20)
print(x, y, last)
```

空集合是 set()，{} 是空字典。字典键和集合元素需要可哈希，列表不能作为普通字典键。tuple 结构不可改，但它包含的可变对象仍可能改变。

## 可变对象与复制

```python
a = [1, 2]
b = a
b.append(3)
print(a)           # [1, 2, 3]
c = a.copy()
c.append(4)
print(a, c)
```

赋值不自动复制列表。浅复制仅复制外层，嵌套列表仍可能共享；需要彻底隔离时了解 copy.deepcopy。NumPy 的视图/副本问题与此相似，但具体规则不同。

## 真值与 None

空容器、空字符串、0、None 通常为假，非空对象通常为真。判断缺少值用 `value is None`。`bool("False")` 为 True，因为它是非空字符串；要解析文本布尔值必须自行定义规则。

练习：把 [80,80,60,90] 按首次出现顺序去重；将字典学生按成绩降序排列；说明 copy 前后修改是否影响原列表。
