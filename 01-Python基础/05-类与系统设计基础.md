# 类、对象与小型系统设计

关键词：class __init__ self 面向对象 类实例 学生成绩系统 系统设计

## 类与对象

类描述一类对象有哪些数据和行为，实例是具体对象。函数放在类里通常叫方法，self 代表调用方法的实例。

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = float(score)

    def is_passed(self):
        return self.score >= 60

    def __repr__(self):
        return f"Student({self.name!r}, {self.score})"

s = Student("小王", 88)
print(s.name, s.is_passed(), s)
```

__init__ 初始化实例，不负责返回新对象；不要在其中 return 非 None。实例属性通常写 self.xxx；放在类体里的属性可能被实例共享，尤其要留意类级别的可变列表。

## 什么时候不需要类

一段 CSV 清洗、统计、绘图流水线，先用函数就足够。需要多个有独立状态的对象、可重复组合的服务或较复杂行为时再引入类。不要为了“系统设计”把每一行代码都包成类。

## 用 dataclass 减少重复定义

```python
from dataclasses import dataclass

@dataclass
class Result:
    count: int
    mean: float

result = Result(count=6, mean=73.33)
print(result)
```

类型标注帮助表达意图，但普通 Python 类型标注不会自动强制所有输入都符合类型。dataclass 的可变默认值要使用 field(default_factory=...)。

## 一个成绩系统的四层职责

1. 输入：CSV、键盘或固定测试数据。
2. 校验：列是否存在、分数能否转数值、范围是否符合要求。
3. 业务：筛选不及格、按班统计、计算平均分。
4. 输出：打印、CSV、JSON、图表。

先让业务层对小数据产生正确结果，再接文件和界面。将路径和阈值作为参数，不要散落在许多函数里。

## 基本需求写法

“计算平均分”还不够，需要规定：缺考算零还是排除？空表怎么办？重复学生怎么处理？输出是否按班级排序？平均分保留几位？这些规则决定代码，而不是代码写完后再猜结果。

## 最小验收

用正常输入、空输入、非法数值、重复记录四种数据检查结果。业务验收关注实际输出，不只是“程序没有报错”。本知识库的示例采用明确的数据和预期结果，你可以用同样方式检查自己的系统。
