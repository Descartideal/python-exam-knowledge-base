# 条件、循环与推导式

关键词：if elif for while range break continue enumerate zip sorted comprehension

## 条件分支

```python
score = 76
if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"
print(level)
```

条件从上到下检查，只进入第一个满足条件的分支。每个分支后的冒号不可省略，同一层用相同缩进。普通对象的多条件可用 and/or/not；Pandas/NumPy 的整列条件要用 &/| 并加括号。

## for 与 range

```python
total = 0
for value in [60, 80, 100]:
    total += value
print(total)
print(list(range(1, 6)))
print(list(range(10, 0, -2)))
```

for 遍历可迭代对象；range 不包括终点，步长不可为 0。求总和可直接 sum，但理解循环有助于分词计数和绘图。

## while、break、continue

```python
n = 0
while n < 5:
    n += 1
    if n == 2:
        continue
    if n == 4:
        break
    print(n)  # 1、3
```

continue 跳过本轮剩余部分，break 退出最近的一层循环。while 必须保证条件有机会变为假；多层循环的 break 不会自动退出所有层。

## enumerate 与 zip

```python
names = ["小王", "小李"]
scores = [80, 60]
for number, name in enumerate(names, start=1):
    print(number, name)
for name, score in zip(names, scores, strict=True):
    print(name, score)
```

enumerate 同时得到编号和元素；zip 将多组元素一一配对。普通 zip 按最短序列截断；Python 3.10+ 的 strict=True 可检查长度是否一致。

## 推导式与生成器表达式

```python
scores = [55, 70, 90, 80]
passed = [s for s in scores if s >= 60]
labels = {s: "pass" if s >= 60 else "fail" for s in scores}
unique = {s // 10 for s in scores}
total = sum(s * s for s in scores)
print(passed, labels, unique, total)
```

列表推导式立即构造列表；生成器表达式按需要逐步产生值，通常不保存完整列表。字典推导式遇到相同键会覆盖值，不适合直接统计重复次数。

## 排序与 key

```python
students = [{"name": "A", "score": 80}, {"name": "B", "score": 95}]
print(sorted(students, key=lambda row: row["score"], reverse=True))
print(sorted([("A", 80), ("B", 80), ("C", 60)], key=lambda p: (-p[1], p[0])))
```

sorted 返回新列表；list.sort 原地修改且返回 None。多条件排序可返回元组；上例先按分数降序，再按名字升序。

## 循环中删除元素

不要一边按原列表遍历一边删除同一列表，会跳过部分元素。用筛选推导式构造新列表。处理异常值时，先明确“跳过、替换、报错”哪种策略。
