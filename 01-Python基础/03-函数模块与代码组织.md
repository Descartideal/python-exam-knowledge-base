# 函数、模块与程序入口

关键词：def return 参数 import as from __name__ 模块 main 函数默认值

## 函数解决重复步骤

```python
def average(values, digits=2):
    if not values:
        raise ValueError("没有数据")
    return round(sum(values) / len(values), digits)

print(average([75, 80, 90]))
print(average([75, 80, 90], digits=1))
```

调用时传入参数，函数内部用局部变量，return 将结果交给调用者。没有 return 时默认返回 None。print 只是显示结果；只有 print 的函数不能直接用于进一步计算。

## 参数、解包与默认值

```python
def add(a, b):
    return a + b

values = (3, 5)
print(add(*values))
options = {"a": 3, "b": 5}
print(add(**options))

def collect(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

不要默认写 `items=[]` 后不断修改，因为默认对象通常在定义函数时建立、后续调用共享。位置参数对应顺序，关键字参数对应名称。`*args` 收集额外位置参数，`**kwargs` 收集额外关键字参数。

## 导入方式

```python
import math
import numpy as np
from collections import Counter
print(math.sqrt(16))
print(np.array([1, 2]))
print(Counter("aba"))
```

as 是起别名，不是安装或复制包。尽量避免 `from module import *`，它会让名称来源不清晰。

## 模块就是可导入的 Python 文件

假设 utils.py 中定义 average，另一个文件可写 `from utils import average`。Python 会沿模块搜索路径查找模块；当前项目文件可能遮蔽同名库，因此不要将练习脚本命名为 numpy.py 等。

## __name__ 与 main

```python
def main():
    print("开始处理数据")

if __name__ == "__main__":
    main()
```

直接运行文件时，__name__ 为 "__main__"；被其他模块导入时通常为模块名。把实际执行步骤放进 main，有助于导入函数时避免自动读取文件、弹窗和写结果。

## 拆分数据处理程序

推荐按职责拆：read_data(path) 读入 → validate(data) 检查 → transform(data) 处理 → save_result(result,path) 输出。核心计算函数尽量返回数据，不混入太多打印和窗口操作。
一个函数太长时，先问“它是否同时做了读取、清洗、计算和绘图”。将每一步独立出来，排错更容易。

## 文档字符串与帮助

函数定义下面的三引号字符串可说明用途、参数、返回值；`help(function)` 能查看它。`dir(module)` 能看模块属性，不能替代阅读参数说明。

练习：写一个函数返回及格人数和平均分；空列表时抛出 ValueError；将函数与运行示例放在同一文件但保证导入时不打印。
