# turtle 函数、批量绘图与交互

关键词：tracer update ontimer onkey onclick mainloop 绘图函数 动画

## 将重复图形写成函数

```python
import turtle

def polygon(t, sides, length):
    if sides < 3:
        raise ValueError("边数至少为 3")
    for _ in range(sides):
        t.forward(length)
        t.left(360 / sides)

t = turtle.Turtle()
t.speed(0)
for _ in range(12):
    polygon(t, 4, 70)
    t.left(30)
turtle.done()
```

函数参数明确传入画笔对象，可避免多个画笔之间的全局状态混乱。每次画完正多边形会回到起点和原方向（允许浮点误差），适合旋转重复图案。

## 批量更新

```python
import turtle
screen = turtle.Screen()
screen.tracer(0)
t = turtle.Turtle()
for i in range(80):
    t.forward(i * 2)
    t.right(91)
screen.update()
turtle.done()
```

tracer(0) 暂停自动刷新，画完调用 update 一次显示；仅 speed(0) 与暂停刷新不是同一机制。画大量线段时适合批量更新。

## 键盘与定时器

```python
import turtle
screen = turtle.Screen()
t = turtle.Turtle()
def step():
    t.forward(10)
def turn():
    t.left(15)
screen.onkey(step, "Up")
screen.onkey(turn, "Left")
screen.listen()
turtle.done()
```

绑定时传函数对象 step，不写 step()，否则会立即执行。点击绘图窗口后操作键盘。ontimer(callback,milliseconds) 可安排下一次回调；持续动画通常让回调再次安排自己，而不是用阻塞无限循环。

onclick 回调通常接收鼠标 x、y。event loop（done/mainloop）维持窗口并分发事件；窗口不关闭、程序不退出是正常行为。

## 常见题型与变式

- 旋转花纹：两层循环，内层画图形，外层转方向。
- 螺旋线：每步距离随 i 增长。
- 同心圆：圆心固定，但 circle 的起点需调整。
- 多画笔：每个 Turtle 保存自己的位置、颜色和朝向。
