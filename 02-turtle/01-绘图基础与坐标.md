# turtle 入门：画笔、坐标、方向与图形

关键词：海龟画图 Turtle Screen 坐标 角度 正多边形 五角星 圆 填充

## 从一个能看到的窗口开始

```python
import turtle
screen = turtle.Screen()
screen.title("我的第一幅图")
screen.setup(width=700, height=500)
t = turtle.Turtle()
t.shape("turtle")
t.forward(100)
t.left(90)
t.forward(80)
turtle.done()
```

默认原点在窗口中心，x 向右为正，y 向上为正。标准模式下初始向右，0° 向右、90° 向上。forward 沿当前方向走，不等于固定向右。

## 绝对定位与相对运动

left/right 在现有朝向上旋转；setheading 直接设定绝对方向；goto 指定绝对坐标。position、heading、xcor、ycor 可以读取状态。

```python
import turtle
t = turtle.Turtle()
t.penup()
t.goto(-100, 50)
t.setheading(0)
t.pendown()
t.forward(150)
print(t.position(), t.heading())
turtle.done()
```

抬笔移动不留线；回到起点可以用 home，但它可能画连线，取决于画笔是否落下。

## 正多边形外角

正 n 边形每步转 360/n 度。填充通常用 begin_fill/end_fill 包住绘制代码。

```python
import turtle
t = turtle.Turtle()
t.color("navy", "gold")
t.begin_fill()
n = 6
for _ in range(n):
    t.forward(70)
    t.left(360 / n)
t.end_fill()
turtle.done()
```

内角不是绘图时每次转的角。五角星五步连线使用 144°，与普通正五边形的 72° 不同。

## 圆与弧

circle(radius,extent) 画圆弧；默认 extent=360。正半径一般把圆心放在朝向的左侧，负半径在右侧。当前画笔点在圆周上，不在圆心。

```python
import turtle
t = turtle.Turtle()
t.circle(50)
t.penup(); t.goto(120, 0); t.pendown()
t.circle(50, extent=180)
t.dot(12, "red")
turtle.done()
```

## 颜色与速度

pencolor 线色、fillcolor 填色、pensize 线宽、speed 动画速度。speed(0) 最快；speed(1) 最慢，不是零速度。RGB 若用 0~255 数值，先 turtle.colormode(255)。
clear 清掉此画笔绘制而通常保留状态，reset 同时恢复画笔状态；hideturtle 隐藏图标，不隐藏画出的线。
