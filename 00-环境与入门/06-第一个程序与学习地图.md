# 第一个程序、运行方式与学习顺序

关键词：新建py 运行脚本 hello world 零基础路线 缩进 终端

## 写第一个程序

在本知识库的「01-Python基础」新建 `hello.py`，文件内容为：

```python
name = "Python"
print(f"你好，{name}！")
scores = [60, 80, 100]
print("平均分：", sum(scores) / len(scores))
```

用记事本保存时选 UTF-8，确认文件名真的是 hello.py，不是 hello.py.txt。在资源管理器里开启文件扩展名显示，有助于检查。

在根目录 PowerShell 运行：

```powershell
python .\01-Python基础\hello.py
```

预期显示“你好，Python！”以及平均分 80.0。直接双击 .py 后窗口可能一闪而过，初学时在终端运行，报错不会立即消失。

## 改代码再运行

把 scores 换成 [55, 65, 90]，先估计均分，再运行核对。代码改动后要保存文件；程序不会自动读取你未保存的编辑。
每学一个函数都做四件事：理解输入、判断返回类型、运行小例子、改一个参数。

## 报错怎么看

Python traceback 最后一行通常是错误类型和原因，上面显示文件与行号。
`SyntaxError` 先查拼写/括号/冒号；`IndentationError` 查缩进；`NameError` 查变量是否定义；`ModuleNotFoundError` 查库和解释器；`FileNotFoundError` 查路径。

用四个空格缩进；不要把中文逗号、中文括号当作 Python 语法字符。字符串内部可以写中文，代码运算符使用半角字符。

## 学习地图

| 阶段 | 看什么 | 做什么 |
|---|---|---|
| 起步 | 环境与入门 01→06 | 会安装一个包、运行一个 .py |
| 语言基础 | 数据类型→控制流→函数模块→文件异常→类与设计 | 自己写成绩统计和文件读取 |
| 数组与表格 | NumPy 入门、索引、统计；Pandas 清洗、分组、合并 | 解释每一步的 shape / 列名 |
| 绘图 | turtle 与 Matplotlib | 画图、改参数、保存图片 |
| 文本 | jieba→Counter→WordCloud | 分词、过滤、词频、字体 |
| 图像 | OpenCV 像素→颜色→处理→轮廓 | 识别 BGR/RGB 和宽高顺序 |
| 综合 | 练习题→扩展题→答案 | 先自己做，再解释答案 |

系统学习时先读各库「入门」或「基础」，需要具体函数时看 API速查，想进一步查参数再看官方资料快照。不要把速查表从头背完当成完整学习。

## 你是否真的会了

- 能说清安装命令在哪里输入，import 写在哪里。
- 能独立安装一个包，并用同一 Python 验证导入。
- 能解释代码中每个变量当前的类型和内容。
- 能换数据、换参数、修复一处错误，而不是只运行原代码。
- 能将大任务拆成读取、验证、处理、输出四个阶段。

这些是学习要求，不是新增的考试命题范围。
