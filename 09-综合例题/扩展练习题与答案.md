# 分级扩展练习与参考答案

关键词：零基础练习 pip练习 判断题 输出题 编程题 广播 merge 轮廓

## 0 级：环境与运行

题 1：终端和 >>> 中哪一个执行 pip？为什么不直接把 pip 命令放进 .py？
答案：安装命令在终端；.py 中应写 Python 语法。pip 命令属于 shell 命令，不是 import。

题 2：安装 OpenCV 与导入分别写什么？
答案：终端 `python -m pip install opencv-python`；Python `import cv2`。turtle 不需要另外安装包。

题 3：装了 numpy 仍报缺失，先查什么？
答案：运行脚本的 sys.executable，再用同一解释器执行 -m pip show numpy；检查编辑器环境和脚本是否重名。

题 4：为本知识库创建环境、安装要求、运行基础例题。
答案：根目录终端依次 `python -m venv .venv`、`.\.venv\Scripts\python.exe -m pip install -r requirements.txt`、`.\.venv\Scripts\python.exe .\01-Python基础\hello.py`。

## 1 级：语言基础

题 5：`[1,2]*2` 和 `np.array([1,2])*2` 输出？
答案：列表为 [1,2,1,2]，数组为 [2,4]。

题 6：`s="Python"`，s[1:4] 和 s[::-1] 输出？
答案：yth、nohtyP。

题 7：列表 a=[1,2]，b=a，b.append(3)，a 如何变化？
答案：[1,2,3]；需要独立外层列表用 a.copy()，嵌套对象另考虑深复制。

题 8：写一个返回平均分的函数，空列表报错。

```python
def average(scores):
    if not scores:
        raise ValueError("没有成绩")
    return sum(scores) / len(scores)

print(average([60, 80, 100]))
```

题 9：统计 [60,80,60,90] 各值次数。
答案：Counter 得到 60→2、80→1、90→1；用 dict.get 累加也可以。

题 10：为什么 CSV 不直接 split(',')？
答案：引号内可能有逗号、换行或转义；用 csv 模块或 Pandas。

## 2 级：NumPy

题 11：数组 [[10,20,30],[40,50,60]] 的 shape、axis=0 均值、axis=1 均值？
答案：(2,3)、[25,35,45]、[20,50]。

题 12：a[:,1] 与 a[:,1:2] 形状分别是什么？
答案：(2,) 与 (2,1)。

题 13：(2,3) 与 (3,) 能相加吗？与 (2,) 呢？
答案：前者能；后者一般不能。每行加两个不同值用 (2,1)。

题 14：a=np.arange(6)，v=a[1:3]，v[0]=99，a 的第二个元素？
答案：99；基础切片通常为视图。用 copy 隔离。

题 15：A=[[1,2],[3,4]]，A*A 与 A@A？
答案：逐元素 [[1,4],[9,16]]；矩阵乘法 [[7,10],[15,22]]。

题 16：求 [60,nan,90] 排除 NaN 的均值，并保存为 .npy。

```python
import numpy as np
a = np.array([60, np.nan, 90])
print(np.nanmean(a))  # 75
np.save("practice-missing.npy", a)
```

## 2 级：Pandas

题 17：index=[10,20] 时 df.loc[10] 与 df.iloc[0] 的区别？
答案：前者按标签 10，后者按第 0 个位置；在此例都指第一行，但规则不同。

题 18：筛选成绩 >=60 且 <90，为什么不能 and？
答案：Series 包含多项真值，and 不能表达逐元素；写 `(df["成绩"]>=60) & (df["成绩"]<90)`。

题 19：缺考是否一定 fillna(0)？
答案：不一定，先定题目规则。排除缺考与缺考算零会得到不同均分。

题 20：每班汇总 mean/max/count，并给每行加班均分？
答案：汇总用 groupby(...)["成绩"].agg([...])，逐行班均分用 transform("mean")。

题 21：两张表按学号对应，使用 concat 还是 merge？
答案：merge；多个班同样列结构按行追加通常 concat。

题 22：同一个班级、科目有多条成绩，pivot 报错怎么办？
答案：先明确是否应聚合；需要均分时 pivot_table(...,aggfunc="mean")。不能未经判断随意删重复。

## 2 级：绘图

题 23：Figure、Axes、Axis 分别是什么？
答案：整张画布、单个绘图区、坐标轴部件。

题 24：比较班级成绩用 bar；看成绩分布用什么？
答案：原始成绩用 hist；预先汇总的分段频数可用 bar。

题 25：一张图出现中文方框，是文件编码还是字体？
答案：通常先查字体覆盖与设置；编码正确也不能补齐缺失字形。

题 26：单子图和 2×2 子图 ax 类型为何变化？
答案：默认 squeeze 会简化维度；使用 squeeze=False 得到统一二维数组。

题 27：turtle 正八边形每步转多少？五角星每步多少？
答案：45°；144°。多边形用外角，不能用内角直接转。

题 28：circle(50) 的当前点是否圆心？
答案：不是，当前点在圆周；圆心相对当前朝向偏在一侧。

## 2 级：文本与词云

题 29：词频统计一般用精确模式还是全模式？
答案：精确模式；全模式有重叠词，定义不同。

题 30：cut 返回什么？lcut 返回什么？
答案：生成器、列表；生成器通常单次迭代消费。

题 31：TF-IDF 权重与 Counter 次数一样吗？
答案：不一样；关键词重要性权重不是原文出现次数。

题 32：中文词云必须先解决哪两件事？
答案：中文分词/词频与支持汉字的字体。

题 33：generate_from_frequencies 会再次按 stopwords 过滤吗？
答案：需要在传入词频之前自行过滤，不依赖构造器的文本处理选项。

题 34：mask 的白色 255 区域通常允许还是禁止放词？
答案：通常禁止；圆形词云可把圆内设 0、圆外设 255。

## 2 级：图像处理

题 35：img.shape=(200,300,3) 表示什么？resize(img,(100,50)) 返回什么 shape？
答案：高200、宽300、三通道；缩放后 (50,100,3)。

题 36：裁剪 y=30:160、x=40:220 后的 shape？
答案：(130,180,3)。

题 37：threshold 返回几个结果？
答案：实际阈值与二值图两个结果。Canny 常返回边缘图一个数组。

题 38：NumPy uint8 加法与 cv2.add 为什么可能不同？
答案：常见 uint8 NumPy 加法溢出回绕；cv2.add 为饱和，截到上限。

题 39：开运算与闭运算的先后次序？
答案：开先腐蚀再膨胀；闭先膨胀再腐蚀。前景定义与核大小决定实际效果。

题 40：轮廓面积是否必然等于非零像素数？
答案：不必然，几何多边形面积与栅格像素计数定义不同。
