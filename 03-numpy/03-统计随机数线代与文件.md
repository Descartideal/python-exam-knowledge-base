# NumPy 统计、随机数、线性代数与文件

关键词：axis std var median percentile argmax nanmean 随机数 seed linalg save load

## axis 的含义是消去哪个维度

```python
import numpy as np
a = np.array([[60, 80, 100], [50, 70, 90]])
print(a.mean())                  # 全部数平均：75
print(a.mean(axis=0))            # 每列：[55,75,95]
print(a.mean(axis=1))            # 每行：[80,70]
print(a.mean(axis=1, keepdims=True).shape)  # (2,1)
print(a - a.mean(axis=1, keepdims=True))
```

keepdims 保留长度为 1 的被消去维度，便于广播。高维数组不要机械记“0 是列、1 是行”，要看具体形状。

## 常见统计接口

| 调用 | 结果含义 |
|---|---|
| sum、mean | 和、平均 |
| min、max | 最小、最大值 |
| argmin、argmax | 最小、最大值的位置 |
| median | 中位数 |
| percentile(a,25) | 第 25 百分位数 |
| var、std | 方差、标准差，默认 ddof=0 |
| unique(a,return_counts=True) | 去重后的值和计数 |
| cumsum | 累积和 |
| any、all | 至少一个真、全部真 |

总体与样本统计要求不同，std(...,ddof=1) 使用样本分母。百分位数计算方法也可调整，题目未指定时不要擅自改变。

## 缺失值 NaN

```python
import numpy as np
a = np.array([60, np.nan, 90])
print(np.mean(a))       # nan
print(np.nanmean(a))    # 75
print(np.isnan(a))
print(np.isfinite(a))
```

NaN 不等于自身，判断用 isnan。nanmean 排除 NaN，但不自动处理无穷值；全是 NaN 仍没有有效平均。缺失值算零或排除是业务规则，不只是技术选择。

## 随机数与可复现

```python
import numpy as np
rng = np.random.default_rng(42)
print(rng.integers(0, 10, size=5))
print(rng.normal(loc=0, scale=1, size=5))
print(rng.choice(["A", "B", "C"], size=2, replace=False))
```

整数上界不包含；normal 的 scale 是标准差；replace=False 表示不放回，抽取数量不可超过可用元素。固定种子用于练习复现，不保证跨所有实现与未来版本完全一致。

## 矩阵与线性方程

```python
import numpy as np
A = np.array([[2., 1.], [1., 3.]])
b = np.array([5., 7.])
x = np.linalg.solve(A, b)
print(x, np.allclose(A @ x, b))
print(np.linalg.det(A))
print(A.T)
```

solve 用于满足条件的线性方程，奇异矩阵可能失败；没必要为了求 Ax=b 先显式求逆。@ 是矩阵乘法，* 是逐元素乘法。向量的转置不会自动变成二维列向量，需要 reshape(-1,1)。

## 保存与加载

```python
import numpy as np
a = np.array([[1.2, 3.4], [5.6, 7.8]])
np.save("practice-array.npy", a)
print(np.load("practice-array.npy", allow_pickle=False))
np.savetxt("practice-array.csv", a, delimiter=",", fmt="%.2f")
print(np.loadtxt("practice-array.csv", delimiter=","))
```

.npy 保留数组类型与形状；文本更容易查看但类型/精度依赖格式。不要为未知来源文件轻率启用 allow_pickle=True。复杂表格列、混合文本、缺失值更适合 Pandas。
