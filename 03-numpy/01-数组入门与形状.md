# NumPy 入门：数组、类型、形状与广播

关键词：ndarray array shape ndim size dtype 广播 broadcasting reshape 数组入门

## 为什么不是普通列表

列表 [1,2,3] 可以存不同类型，列表乘 2 表示重复。NumPy 数组通常使用统一元素类型，支持整批数值运算。导入习惯是 `import numpy as np`；np 是人为约定的别名。

```python
import numpy as np
print([1, 2, 3] * 2)
print(np.array([1, 2, 3]) * 2)
```

预期列表变成六个元素，数组变成 [2,4,6]。数组运算不需要写逐个元素的 Python 循环。

## 创建与属性

```python
import numpy as np
a = np.array([[10, 20, 30], [40, 50, 60]], dtype=float)
print(a.ndim)   # 2 维
print(a.shape)  # (2,3)，2 行 3 列
print(a.size)   # 6 个元素
print(a.dtype)  # 浮点类型
print(a.astype(int))
```

shape 是元组，不用写 shape()；size 是元素个数，len(a) 在二维数组上是第一维长度。astype 转换会得到相应类型数组；转整数会截断小数。
混合字符串和数字可能得到字符串数组或 object 类型，不能假定所有 array 都能正常做数值计算。

## 常见创建方法

| 调用 | 作用 | 注意 |
|---|---|---|
| np.arange(2,10,2) | [2,4,6,8] | 不含终点 |
| np.linspace(0,1,5) | 5 个均匀点 | 默认含两端 |
| np.zeros((2,3)) | 2×3 全零 | 默认 float |
| np.ones((2,3),dtype=int) | 整数全一 | 形状用元组 |
| np.full((2,3),7) | 全为 7 | 指定填充值 |
| np.eye(3) | 3×3 单位矩阵 | 主对角为 1 |
| np.empty((2,3)) | 分配未初始化数组 | 值不可当作已知数据 |

## reshape 与转置

```python
import numpy as np
a = np.arange(12)
b = a.reshape(3, 4)
print(b)
print(b.reshape(2, -1).shape)  # (2,6)
print(b.T.shape)             # (4,3)
print(b.flatten())
```

元素数量必须保持；一个 -1 让 NumPy 自动推算该维长度。reshape 按元素存储顺序重组，转置 T 交换轴，它们不是同一种操作。flatten 总是复制，ravel 在可行时返回视图。

## 广播从右往左比较

形状对齐时，对应维度必须相同，或者其中一个是 1；缺失的前导维度按 1 看。以 2×3 表格为例：

```python
import numpy as np
a = np.array([[1, 2, 3], [4, 5, 6]])
print(a + 10)                         # 所有元素加 10
print(a + np.array([10, 20, 30]))       # 每列加不同数
print(a + np.array([[100], [200]]))     # 每行加不同数
```

(2,3)+(3,) 可以，(2,3)+(2,1) 可以，(2,3)+(2,) 通常不可以，因为尾部 3 与 2 不兼容。需要按行加时把 (2,) 变成 (2,1)，可用 `values[:,None]`。

## 空数组与类型边界

空数组 mean 可能得到 nan 并警告，max 可能无法计算；统计前检查 size。整数数组赋值小数可能截断；需要小数先用 float。NaN 通常使用浮点表示，不能直接保存到普通整数数组。
