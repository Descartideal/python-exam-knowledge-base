# NumPy 索引、切片、视图与数组组合

关键词：布尔索引 花式索引 fancy indexing copy view concatenate stack split where

## 二维索引先行后列

```python
import numpy as np
a = np.arange(12).reshape(3, 4)
print(a[1, 2])       # 6
print(a[1, :])       # 第二行，shape=(4,)
print(a[:, 1])       # 第二列，shape=(3,)
print(a[:, 1:2])     # 保留列维度，shape=(3,1)
print(a[0:2, 1:3])   # 2×2 区域
print(a[::-1, :])    # 反转行序
```

`a[:,1]` 与 `a[:,1:2]` 的值相似，但维度不同，会影响广播与后续函数。单个索引一般会去掉那一维，切片通常保留它。

## 多条件筛选

```python
import numpy as np
a = np.array([45, 60, 75, 90])
mask = (a >= 60) & (a < 90)
print(mask)
print(a[mask])
a[a < 60] = 60
print(a)
```

mask 是布尔数组，必须与对应被索引维度匹配。二维数组用同形状布尔 mask 取元素时，通常得到一维元素序列；要取整行，先得到每行的条件。

```python
import numpy as np
a = np.array([[50, 80], [70, 90], [40, 55]])
print(a[(a >= 60).all(axis=1)])  # 每科都及格的行
print(a[(a >= 90).any(axis=1)])  # 至少一科 >=90 的行
```

## 基础切片常共享数据

```python
import numpy as np
a = np.arange(6)
view = a[1:4]
view[0] = 99
print(a)  # 第二个元素变成 99
independent = a[1:4].copy()
independent[0] = -1
print(a)  # 不再受影响
```

基础切片通常得到视图；整数数组索引/布尔索引属于高级索引，通常得到副本。需要明确隔离时主动 .copy()，不要靠猜测。

## 花式索引与排列

```python
import numpy as np
a = np.array([50, 80, 70])
print(a[[2, 0]])  # [70,50] 选择指定位置
order = np.argsort(a)
print(order, a[order])
```

二维 `a[[0,2],[1,3]]` 选择配对坐标 (0,1)、(2,3)，不自动生成 2×2 交叉区域。需要行列交叉可用 `a[np.ix_([0,2],[1,3])]`。

## 拼接与堆叠

```python
import numpy as np
a = np.array([[1, 2], [3, 4]])
b = np.array([[5, 6]])
print(np.concatenate([a, b], axis=0))  # 沿已有行轴合并，3×2
print(np.stack([a, a], axis=0).shape)  # 新增轴，2×2×2
print(np.split(np.arange(6), 3))
```

concatenate 使用已有轴，其他轴长度必须匹配；stack 增加新轴，输入数组形状必须一致。split 通常要求等分，array_split 可处理不能整除的长度。

## where 与非零位置

```python
import numpy as np
a = np.array([50, 80, 70])
print(np.where(a >= 60, a, 0))
print(np.where(a >= 60))  # 仅 condition 时返回索引元组
print(np.nonzero(a >= 60))
```

where 的“三参数条件替换”和“单参数找索引”返回类型不同，读题时先确认要值还是位置。

练习：取第 1、3 行与第 2、4 列交叉区；筛选行均分 >=70 的行；用副本修改一个区域且保证原数组不变。
