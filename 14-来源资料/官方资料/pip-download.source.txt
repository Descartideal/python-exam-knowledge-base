<section id="description">
<h2>Description<a class="headerlink" href="#description" title="Link to this heading">¶</a></h2>
<p><p>Download packages from:</p>
<ul class="simple">
<li><p>PyPI (and other indexes) using requirement specifiers.</p></li>
<li><p>VCS project urls.</p></li>
<li><p>Local project directories.</p></li>
<li><p>Local or remote source archives.</p></li>
</ul>
<p>pip also supports downloading from “requirements files”, which provide
an easy way to specify a whole environment to be downloaded.</p>
</p>
<section id="overview">
<h3>Overview<a class="headerlink" href="#overview" title="Link to this heading">¶</a></h3>
<p><code class="docutils literal notranslate"><span class="pre">pip</span> <span class="pre">download</span></code> does the same resolution and downloading as <code class="docutils literal notranslate"><span class="pre">pip</span> <span class="pre">install</span></code>,
but instead of installing the dependencies, it collects the downloaded
distributions into the directory provided (defaulting to the current
directory). This directory can later be passed as the value to <code class="docutils literal notranslate"><span class="pre">pip</span> <span class="pre">install</span>
<span class="pre">--find-links</span></code> to facilitate offline or locked down package installation.</p>
<p><code class="docutils literal notranslate"><span class="pre">pip</span> <span class="pre">download</span></code> with the <code class="docutils literal notranslate"><span class="pre">--platform</span></code>, <code class="docutils literal notranslate"><span class="pre">--python-version</span></code>,
<code class="docutils literal notranslate"><span class="pre">--implementation</span></code>, and <code class="docutils literal notranslate"><span class="pre">--abi</span></code> options provides the ability to fetch
dependencies for an interpreter and system other than the ones that pip is
running on. <code class="docutils literal notranslate"><span class="pre">--only-binary=:all:</span></code> or <code class="docutils literal notranslate"><span class="pre">--no-deps</span></code> is required when using any
of these options. It is important to note that these options all default to the
current system/interpreter, and not to the most restrictive constraints (e.g.
platform any, abi none, etc). To avoid fetching dependencies that happen to
match the constraint of the current interpreter (but not your target one), it
is recommended to specify all of these options if you are specifying one of
them. Generic dependencies (e.g. universal wheels, or dependencies with no
platform, abi, or implementation constraints) will still match an over-
constrained download requirement. If some of your dependencies are not
available as binaries, you can build them manually for your target platform
and let pip download know where to find them using <code class="docutils literal notranslate"><span class="pre">--find-links</span></code>.</p>
<div class="admonition note">
<p class="admonition-title">Note</p>
<p>To determine the appropriate values for <code class="docutils literal notranslate"><span class="pre">--python-version</span></code> and <code class="docutils literal notranslate"><span class="pre">--platform</span></code>, you can query the target system using the following commands:</p>
<ul class="simple">
<li><p>For the Python version, use <a class="reference external" href="https://docs.python.org/3/library/sysconfig.html#sysconfig.get_python_version" title="(in Python v3.14)"><code class="xref py py-func docutils literal notranslate"><span class="pre">sysconfig.get_python_version()</span></code></a>.</p></li>
<li><p>For the platform, use <a class="reference external" href="https://packaging.pypa.io/en/stable/tags.html#packaging.tags.platform_tags" title="(in Packaging v26.3)"><code class="xref py py-func docutils literal notranslate"><span class="pre">packaging.tags.platform_tags()</span></code></a>.</p></li>
</ul>
</div>
</section>

</dd></dl>

</p>
<p><span class="target" id="download-index-url"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-i">
<span id="cmdoption-index-url"></span><span class="sig-name descname"><span class="pre">-i</span></span><span class="sig-prename descclassname"></span><span class="sig-prename descclassname"><span class="pre">,</span> </span><span class="sig-name descname"><span class="pre">--index-url</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;url&gt;</span></span><a class="headerlink" href="#cmdoption-i" title="Link to this definition">¶</a></dt>
<dd><p>Base URL of the Python Package Index (default <a class="reference external" href="https://pypi.org/simple">https://pypi.org/simple</a>). This should point to a repository compliant with PEP 503 (the simple repository API) or a local directory laid out in the same format.</p>

<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_NO_INDEX</span></code>)</p>
</dd></dl>

<span class="target" id="download-refresh-package"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-refresh-package">
<span class="sig-name descname"><span class="pre">--refresh-package</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;refresh_package&gt;</span></span><a class="headerlink" href="#cmdoption-refresh-package" title="Link to this definition">¶</a></dt>
<dd><p>Refresh package index information for the given packages instead of using cached responses. Accepts ‘:all:’ to apply to all packages, or a comma-separated list of package names.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_REFRESH_PACKAGE</span></code>)</p>
</dd></dl>

<span class="target" id="download-find-links"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-f">
<span id="cmdoption-find-links"></span><span class="sig-name descname"><span class="pre">-f</span></span><span class="sig-prename descclassname"></span><span class="sig-prename descclassname"><span class="pre">,</span> </span><span class="sig-name descname"><span class="pre">--find-links</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;url&gt;</span></span><a class="headerlink" href="#cmdoption-f" title="Link to this definition">¶</a></dt>
<dd><p>If a URL or path to an html file, then parse for links to archives such as sdist (.tar.gz) or wheel (.whl) files. If a local path or <a class="reference external" href="file://">file://</a> URL that’s a directory, then look for archives in the directory listing. Links to VCS project URLs are not supported.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_FIND_LINKS</span></code>)</p>
</dd></dl>

<span class="target" id="download-uploaded-prior-to"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-uploaded-prior-to">
<span class="sig-name descname"><span class="pre">--uploaded-prior-to</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;datetime_or_duration&gt;</span></span><a class="headerlink" href="#cmdoption-uploaded-prior-to" title="Link to this definition">¶</a></dt>
<dd><p>Only consider packages uploaded prior to the given value. Accepts an ISO 8601 datetime (e.g., ‘2023-01-01T00:00:00Z’, uses local timezone if none specified) or a duration in days (e.g., ‘P3D’ for packages uploaded at least 3 days ago). Only effective when using indexes that provide upload-time metadata.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_UPLOADED_PRIOR_TO</span></code>)</p>
</dd></dl>

<dt class="sig sig-object std" id="cmdoption-pre">

<dd><p>Include pre-release and development versions. By default, pip only finds stable versions.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_PRE</span></code>)</p>

<span class="target" id="download-all-releases"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-all-releases">
<span class="sig-name descname"><span class="pre">--all-releases</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;release_control&gt;</span></span><a class="headerlink" href="#cmdoption-all-releases" title="Link to this definition">¶</a></dt>
<dd><p>Allow all release types (including pre-releases) for a package. Can be supplied multiple times, and each time adds to the existing value. Accepts either “:all:” to allow pre-releases for all packages, “:none:” to empty the set (notice the colons), or one or more package names with commas between them (no colons). Cannot be used with --pre.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_ALL_RELEASES</span></code>)</p>
</dd></dl>

<span class="target" id="download-only-final"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-only-final">
<span class="sig-name descname"><span class="pre">--only-final</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;release_control&gt;</span></span><a class="headerlink" href="#cmdoption-only-final" title="Link to this definition">¶</a></dt>
<dd><p>Only allow final releases (no pre-releases) for a package. Can be supplied multiple times, and each time adds to the existing value. Accepts either “:all:” to disable pre-releases for all packages, “:none:” to empty the set, or one or more package names with commas between them. Cannot be used with --pre.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_ONLY_FINAL</span></code>)</p>
</dd></dl>

<span class="target" id="download-no-binary"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-no-binary">
<span class="sig-name descname"><span class="pre">--no-binary</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;format_control&gt;</span></span><a class="headerlink" href="#cmdoption-no-binary" title="Link to this definition">¶</a></dt>
<dd><p>Do not download binary packages. Cached binary packages may still be used. Can be supplied multiple times, and each time adds to the existing value. Accepts either ‘:all:’ to disable all binary packages, ‘:none:’ to empty the set (notice the colons), or one or more package names with commas between them (no colons). Note that some packages are tricky to compile and may fail to install when this option is used on them.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_NO_BINARY</span></code>)</p>
</dd></dl>

<span class="target" id="download-only-binary"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-only-binary">
<span class="sig-name descname"><span class="pre">--only-binary</span></span><span class="sig-prename descclassname"> <span class="pre">&lt;format_control&gt;</span></span><a class="headerlink" href="#cmdoption-only-binary" title="Link to this definition">¶</a></dt>
<dd><p>Do not use source packages. Can be supplied multiple times, and each time adds to the existing value. Accepts either “:all:” to disable all source packages, “:none:” to empty the set, or one or more package names with commas between them. Packages without binary distributions will fail to install when this option is used on them.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_ONLY_BINARY</span></code>)</p>
</dd></dl>

<span class="target" id="download-prefer-binary"></span><dl class="std option">
<dt class="sig sig-object std" id="cmdoption-prefer-binary">
<span class="sig-name descname"><span class="pre">--prefer-binary</span></span><span class="sig-prename descclassname"></span><a class="headerlink" href="#cmdoption-prefer-binary" title="Link to this definition">¶</a></dt>
<dd><p>Prefer binary packages over source packages, even if the source packages are newer.</p>
<p>(environment variable: <code class="docutils literal notranslate"><span class="pre">PIP_PREFER_BINARY</span></code>)</p>
</dd></dl>
