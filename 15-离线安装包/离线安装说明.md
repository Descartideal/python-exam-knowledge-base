# 本地库安装包说明

这里保存了 NumPy、Pandas、Matplotlib、jieba、WordCloud、OpenCV、Pillow、openpyxl 以及它们的依赖 wheel 文件。安装使用本地文件，不联系 PyPI 或镜像。

## 适用环境

- Windows 64 位（Intel/AMD），Python 3.12。
- Python 本身及 pip/venv 需预先安装；turtle 图形窗口需要 Tk。
- 本目录不包含 Python 安装器，不能在没有 Python 的电脑上直接运行 .py。
- 中文绘图使用 Windows 本机的微软雅黑/黑体/宋体字体；不从网络下载字体。

## 最简单的安装方式

在知识库根目录双击「安装学习环境.cmd」。它创建 .venv，然后只从本目录 wheels 安装库。缺少包或版本不匹配会直接报错，不会偷偷联网补包。

## 手动安装

在根目录 PowerShell 执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links .\15-离线安装包\wheels -r .\15-离线安装包\requirements-离线.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe tools\check_environment.py
```

--no-index 禁止访问在线包索引；--find-links 指向本地安装文件。全部版本已固定在 requirements-离线.txt 中，安装文件名和校验值记录在 安装包清单.json。

## 考前复制

复制整个知识库文件夹，包含本目录、各章节与测试数据。虚拟环境不能保证复制后路径仍有效：换电脑时使用本地 wheel 重新创建环境，或者选用考场已有的 Python 环境。
考试现场不要依赖联网 pip 安装；若学校环境版本不同，提前在指定环境测试例题。文字资料、搜索与官方正文无需安装 Python 也可以阅读。
