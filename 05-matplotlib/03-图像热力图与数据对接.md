# Matplotlib 图像、热力图、误差与数据对接

关键词：imshow cmap colorbar BGR RGB errorbar Pandas 绘图 NumPy热力图

## 二维数组画热力图

```python
import numpy as np
import matplotlib.pyplot as plt
a = np.array([[60, 80, 90], [70, 75, 95]])
fig, ax = plt.subplots()
image = ax.imshow(a, cmap="YlGnBu", vmin=0, vmax=100)
fig.colorbar(image, ax=ax, label="score")
ax.set_xticks([0, 1, 2], ["Math", "English", "Python"])
ax.set_yticks([0, 1], ["Class A", "Class B"])
fig.tight_layout()
fig.savefig("practice-heatmap.png", dpi=150)
plt.close(fig)
```

imshow 可显示二维标量数据，也可显示 RGB/RGBA 图像。cmap 是色图，colorbar 解释颜色与数值关系。比较多张热力图时固定 vmin/vmax，避免每图独立缩放造成误读。

## OpenCV 图像显示前转通道

OpenCV 常读成 BGR；Matplotlib 彩图通常按 RGB。灰度图要传 cmap="gray"；只给二维数组而不指定色图，会默认映射成伪彩色。

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt
bgr = np.zeros((60, 100, 3), dtype=np.uint8)
bgr[:, :] = (0, 0, 255)
rgb = cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)
fig, ax = plt.subplots()
ax.imshow(rgb)
ax.axis("off")
fig.savefig("practice-red.png", dpi=150)
plt.close(fig)
```

RGB 浮点图通常应落在 0~1，整数图通常为 0~255；不要随意把不同范围的数据当成同一种图像。

## Pandas 分组结果接绘图

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.DataFrame({"class": ["A", "A", "B"], "score": [60, 90, 80]})
result = df.groupby("class")["score"].mean().sort_values(ascending=False)
fig, ax = plt.subplots()
ax.bar(result.index.astype(str), result.to_numpy())
ax.set_ylabel("Mean score")
fig.savefig("practice-group-plot.png", dpi=150)
plt.close(fig)
```

先清洗与统计，再绘图。不能让图表替代检查分组样本数量；一个只有一名学生的班均分，与多学生班级比较时含义需说清。

## 误差棒与双轴

errorbar(x,y,yerr=...) 展示指定误差，yerr 是标准差、标准误还是区间需明确说明。twinx 创建共享 x 的另一 y 轴，适合不同单位的数据，但应让轴标签与曲线清晰对应。
颜色、线型和标记应配合使用，图例只写“蓝线”不如写变量名。
