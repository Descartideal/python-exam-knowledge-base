# 子图、中文字体、注释与文件输出

关键词：中文方框 字体 FontProperties subplots squeeze tight_layout savefig close dpi

## 子图返回类型

```python
import matplotlib.pyplot as plt
fig, axes = plt.subplots(2, 2, squeeze=False, figsize=(8, 6))
for row in range(2):
    for col in range(2):
        ax = axes[row, col]
        ax.plot([1, 2, 3], [row + 1, col + 2, 3])
        ax.set_title(f"Panel {row},{col}")
fig.tight_layout()
fig.savefig("practice-panels.png", dpi=150)
plt.close(fig)
```

默认只有 1 个子图时返回单个 Axes；1×N 时常为一维数组；多行多列时为二维数组。squeeze=False 始终返回二维数组，减少小布局变化引起的索引错误。

sharex/sharey 共享坐标范围；每个 ax 仍是独立绘图区。fig.suptitle 设置整张图标题，ax.set_title 设置某个子图标题。

## 中文字体

```python
from pathlib import Path
import matplotlib.pyplot as plt
from matplotlib.font_manager import FontProperties
font_path = Path("C:/Windows/Fonts/msyh.ttc")
if not font_path.exists():
    raise FileNotFoundError("改为你的中文字体路径")
font = FontProperties(fname=str(font_path))
fig, ax = plt.subplots()
ax.bar(["A", "B"], [70, 85])
ax.set_title("班级成绩", fontproperties=font)
ax.set_ylabel("平均分", fontproperties=font)
fig.savefig("practice-chinese.png", dpi=150, bbox_inches="tight")
plt.close(fig)
```

设置 fontproperties 只影响指定文字；全图可用 rcParams 配置可用中文字体名称。字体文件存在不代表所有字符均覆盖。负号缺字时可了解 axes.unicode_minus；先确定字体，而非只换编码。

## 数据标签与注释

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
bars = ax.bar(["A", "B"], [70, 85])
ax.bar_label(bars, fmt="%.1f", padding=3)
ax.set_ylim(0, 100)
ax.annotate("Highest", xy=(1, 85), xytext=(0.5, 95), arrowprops={"arrowstyle": "->"})
fig.savefig("practice-annotation.png", dpi=150)
plt.close(fig)
```

text 放普通文字；annotate 可以连箭头。默认坐标通常是数据坐标，Axes 比例坐标需显式指定 transform 或相应参数。

## 保存、显示与关闭

fig.savefig 在指定画布上保存；plt.savefig 保存当前活动画布。PNG 适合位图，SVG/PDF 适合矢量输出（图中的栅格图像仍是栅格）；dpi 控制栅格分辨率。
先保存再 show；批量任务及时 close(fig) 避免积累内存。无图形桌面时，在 import pyplot 前设置 matplotlib.use("Agg")，只输出文件。
本知识库的可运行绘图例题使用 Agg，不弹窗；图在 13-运行结果 中。
